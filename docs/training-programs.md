# Training programs

A training program is a goal-directed strategy between the lasting `user-profile.md` and individual workouts in `plans/`. Keep the user's stable constraints and preferences in the profile; keep exercise prescriptions and expected durations in workout plans; keep performed work in sessions. A program records why and how a series of workouts is organized, not their set-by-set prescription. A program can have a review point without a fixed end date.

Save an agreed program as `training-programs/<unique-id>.md`. Use a title and explicit ID, then record only what is known: goal and priorities, intended review trigger, weekly schedule, workload emphasis, relevant adjustment boundaries, and nutrition direction if agreed. A review date need not be invented before the program starts. Workout plans identify their program with `training_program_id`; that link is authoritative, so do not maintain a required plan list in the program. An outline is not a saved workout plan: approve and save individual plans before running them.

`workspace.yaml` may have `active_training_program: training-programs/<unique-id>.md`. Omit this key when no program is active; `status` still describes setup only. Read the active program when designing its workouts and when evaluating progress against its goals. Plans created for a program carry `training_program_id: <unique-id>`; historical plans without this field stand alone. Sessions continue to reference their exact workout plan; the plan identifies the program. Do not retrofit historical plans or infer membership from dates.

One program is active at a time. At review, record observations with links to sessions; do not replace performed results or edit plans referenced by results. Append dated notes for adjustments within the same strategy rather than rewriting its original intent; a new goal or substantially different strategy gets a new program ID and file. Clear or change the active pointer accordingly. Keep old programs for history. No universal program length, progression rule, or nutrition prescription is implied.
