# Maintain training preferences

Work from the repository root. Follow `AGENTS.md` for setup status and onboarding. Read existing `user-profile.md` before changing goals, constraints or programming preferences; save the user's stated preference there in plain language without inventing universal rules. Read `catalog/equipment.yaml` and `docs/exercise-catalog.md` before changing available equipment; retain equipment IDs referenced by approved exercises, marking unavailable items rather than deleting them. Clarify ambiguous requests rather than overwriting existing choices. Tell the user what was saved. Changes to a reusable plan require a separate request and repwerks-plan; historical plans and results remain intact. Changes to general trainer behavior or workflow belong in the relevant skill instructions, not in the personal profile; clarify scope before making them.
